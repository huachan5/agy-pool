# agy-pool M1 / M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build and test local task handoffs and manually guided, account-verified Windows relays.

**Architecture:** Four modules: `store` controls SQLite and local artifacts, `handoff` composes bounded Markdown, `runtime` owns Windows and HUD probes, and `cli` wires typed operations together. M2 exercises workflow through real SQLite and synthetic runtime fixtures; browser/Google verification is a manual M4 check.

**Tech Stack:** Python 3.12 standard library, SQLite WAL, pytest for tests, Win32 via ctypes.

**Spec:** [v2.3](../../agy-pool-技术方案.md), [additional acceptance cases](../../agy-pool-v2.3-acceptance.md).

## Global Constraints

Windows 10/11; Python 3.12; no external runtime dependencies; do not modify `agy-hud`; no credentials or full emails in pool database, anchors, or handoffs; no live OAuth in tests; no commits or push requested. Anchor ≤ 600 and handoff ≤ 3,500 estimated tokens. Keep handoff artifacts; defer `resume` and HUD changes.

## Review Focus

- Two databases with the same human-readable segment ID never share artifacts.
- GUI switch canceled after manual login does not restore the Google account; `start` still requires matching identity.
- No pre-login or shared HUD state authorizes a relay. A fresh no-prompt verification process must publish usable state.
- A failed launch is audited and retry reuses the next successful segment sequence.
- Unbounded task or Git output cannot push a complete safe anchor out of the 3,500-token handoff.

## Implementation notes

- Ruling: Use `Local\` mutex within one Windows sign-in session and per-database artifact directories. This avoids cross-pool mixing without implying cross-user session coordination.
- Ruling: Launch a fresh no-prompt verification process after manual account setup so a pre-login HUD file cannot authorize work. Its real HUD behavior is part of M4, not mocked acceptance.
- Final review: Added regression tests for frozen handoffs after launch failure and for `token:` / JSON `secret` text. Verified failures before the fixes and passing targeted suites afterwards.
